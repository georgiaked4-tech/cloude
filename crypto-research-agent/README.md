# Crypto Research Agent

Безопасный MVP для исследования крипторынка, детерминированных сигналов,
бэктестов и paper trading. Агент не содержит кода отправки биржевых ордеров.

## Возможности

- загрузка публичных OHLCV-свечей Bybit через CCXT;
- хранение данных и результатов в SQLite;
- референсная EMA cross стратегия;
- единый риск-модуль для бэктеста и paper-режима;
- учёт taker-комиссии и проскальзывания;
- RSS-новости с детерминированным фильтром по ключевым словам и текстовый
  дайджест через Anthropic (на сигналы не влияет);
- Telegram-команды `/status`, `/report`, `/stop` и исходящие уведомления;
- метрики до и после комиссий, Sharpe с годовым пересчётом по таймфрейму;
- состояние paper-режима (баланс, открытая позиция, дневной PnL) хранится в
  SQLite, поэтому запуск по расписанию продолжает прошлый прогон.

## Быстрый старт

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e '.[dev]'
cp .env.example .env
python scripts/backfill.py --symbol BTC/USDT --timeframe 1h --limit 1000
python scripts/run_backtest.py --symbol BTC/USDT --timeframe 1h
python scripts/run_paper.py --symbol BTC/USDT --timeframe 1h --once
python scripts/run_digest.py --save-only
```

Запускать команды следует из корня проекта. База `data/agent.db` создаётся
автоматически. Ключ Anthropic и Telegram-токен необязательны для загрузки
рынка и бэктеста.

`run_paper.py` рассчитан на запуск по расписанию: он обрабатывает только
закрытые свечи, появившиеся после прошлого прогона, и восстанавливает открытую
позицию и баланс из базы. Незакрытая (текущая) свеча всегда отбрасывается.
`run_digest.py` без `--save-only` требует `ANTHROPIC_API_KEY`.

## Безопасность

`.env` не коммитится. Код использует только публичные биржевые данные.
Стратегия не вызывает LLM, а paper broker лишь имитирует исполнение.
Telegram-команды `/status`, `/report`, `/stop` выполняются только для
`TELEGRAM_CHAT_ID` из `.env`; сообщения из других чатов игнорируются.
