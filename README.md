# Агент мониторинга финансовых рынков

Автоматический сбор новостей из RSS-фидов, отслеживание цен криптовалют и отправка дайджестов в Telegram-канал.

## Возможности

- Сбор новостей из 8 источников (РБК, Smart-Lab, Финам, CoinDesk, CoinTelegraph, Yahoo Finance, MarketWatch, Investing.com)
- Скоринг новостей по ключевым словам (BTC, ETH, S&P, нефть, рубль, ФРС и др.)
- Цены BTC/ETH через бесплатный CoinGecko API
- Утренний и вечерний дайджест по расписанию
- Ценовые алерты при изменении на ≥5%
- Chunked-отправка длинных сообщений (>4096 символов)

## Быстрый старт

### 1. Создать Telegram-бота

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/newbot`, задайте имя и username
3. Скопируйте полученный **токен** (формат: `123456:ABC-DEF...`)

### 2. Добавить бота в канал

1. Создайте канал (или используйте существующий)
2. Зайдите в настройки канала → **Администраторы** → **Добавить администратора**
3. Найдите вашего бота по username и добавьте его
4. Дайте право **отправлять сообщения**

### 3. Получить chat_id канала

**Вариант А** — для публичных каналов: используйте `@username_канала` (например `@my_finance_channel`).

**Вариант Б** — для приватных каналов:
1. Перешлите любое сообщение из канала боту [@userinfobot](https://t.me/userinfobot)
2. Скопируйте ID (формат: `-100...`)

### 4. Установить зависимости

```bash
pip install -r requirements.txt
```

### 5. Запустить

```bash
# Задать переменные окружения
export TELEGRAM_BOT_TOKEN="123456:ABC-DEF..."
export TELEGRAM_CHAT_ID="@my_channel"

# Разовый дайджест
python agent.py --once

# Бесконечный цикл (утро + вечер + алерты)
python agent.py
```

## Структура проекта

```
config.py         — настройки (токен, chat_id, интервалы, пороги)
sources.py        — RSS-источники и ключевые слова
agent.py          — основной код агента (сбор, форматирование, отправка)
requirements.txt  — зависимости
```

## Настройка

Все параметры в `config.py`:

| Параметр | По умолчанию | Описание |
|---|---|---|
| `MORNING_DIGEST_HOUR` | 6 | Час утреннего дайджеста (UTC) |
| `EVENING_DIGEST_HOUR` | 18 | Час вечернего дайджеста (UTC) |
| `PRICE_CHECK_INTERVAL` | 300 | Интервал проверки цен (сек) |
| `PRICE_ALERT_THRESHOLD` | 5.0 | Порог алерта (%) |
| `MAX_NEWS_PER_DIGEST` | 15 | Макс. новостей в дайджесте |

Источники и ключевые слова — в `sources.py`.
