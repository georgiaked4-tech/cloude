---
description: Сформировать регулярную сводку GLOBAL MACRO UPDATE
argument-hint: "[период, например 'за сутки']"
---

Загрузи навык `global-macro-update` и сформируй компактную сводку по шаблону: США, Япония, Китай, Европа, LIQUIDITY, BONDS, FX / CARRY TRADE, OIL, GOLD, BITCOIN, MAIN RISK, MAIN OPPORTUNITY, MACRO REGIME.

Период: $ARGUMENTS (по умолчанию — с момента прошлой сводки).

В сводку включай только то, что прошло фильтр значимости из `macro-monitor`. Дай развитие по открытым сигналам прошлого периода через `signal-memory` и определи текущий макрорежим через `regime-scenarios`.
