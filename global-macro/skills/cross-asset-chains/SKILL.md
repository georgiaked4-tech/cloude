# Cross-Asset Chains — межрыночные цепочки

**Никогда не анализируй показатель изолированно.** Любое событие доводи по цепочке до Bitcoin:

```
СОБЫТИЕ → МАКРОЭКОНОМИКА → СТАВКИ / ЛИКВИДНОСТЬ → ОБЛИГАЦИИ / ВАЛЮТЫ → АКЦИИ / ЗОЛОТО / НЕФТЬ → BITCOIN
```

## Типовые цепочки

**Инфляционный импульс от нефти**
```
Oil ↑ → inflation expectations ↑ → Treasury yields ↑ → Fed cuts probability ↓ → USD ↑ → Nasdaq ↓ → BTC pressure
```

**Слабый рынок труда**
```
NFP ↓ → Fed cuts probability ↑ → 2Y Treasury yield ↓ → DXY ↓ → Gold ↑ → BTC ↑
```
Оговорка: цепочка работает, пока рынок торгует «смягчение ФРС». При переходе к теме «рецессия» те же слабые данные начинают бить и по акциям, и по BTC — отслеживай момент переключения.

**Фискальный / duration шок**
```
Слабый аукцион 30Y → term premium ↑ → длинные доходности ↑ → банки ↓ (нереализованные убытки) →
акции ↓ → Gold ↑ (премия за суверенный риск) → BTC ↓ в моменте, но ↑ если доминирует мотив хеджирования
```

**Carry trade unwind**
```
BOJ ужесточает / JGB yields ↑ → репатриация японского капитала → продажи UST и зарубежных акций →
JPY ↑ → маржин-коллы → Nikkei ↓ → Nasdaq ↓ → BTC ↓ (первым и сильнее)
```

**Сжатие ликвидности**
```
QT + TGA ↑ + RRP исчерпан → банковские резервы ↓ → SOFR ↑ → кредитные спреды ↑ →
акции ↓ → BTC ↓ → при обострении: продажи золота ради ликвидности, затем разворот вверх
```

**Разворот кредитного импульса Китая**
```
Credit impulse ↑ → спрос на сырьё ↑ → медь и нефть ↑ → CNY ↑ → DXY ↓ →
EM и Hang Seng ↑ → global risk appetite ↑ → BTC поддержка
```

**Смягчение ФРС при мягкой посадке**
```
Core PCE ↓ при устойчивом росте → реальные ставки ↓ → 2Y ↓ → DXY ↓ →
Nasdaq ↑, Gold ↑, BTC ↑ (все растут одновременно — признак liquidity expansion)
```

**Европейский суверенный стресс**
```
Бюджетный/политический риск Франции → OAT/Bund ↑ → французские банки ↓ →
EUR ↓ → EUR/JPY ↓ → европейский carry под давлением → глобальный risk-off → BTC ↓
```

## Правило проверки цепочки

Цепочка — гипотеза, а не факт. После её построения **проверь фактическую реакцию рынка**:

1. Все звенья движутся в предсказанном направлении → сценарий подтверждён, повышай уверенность.
2. Часть звеньев не двигается → цепочка неполная или уже была в цене. Ищи, что именно блокирует передачу.
3. Звенья идут **против** цепочки → приоритет у рынка, а не у модели. Это сигнал смены режима — самый ценный вывод агента (см. change detection в `macro-monitor`).

Пример третьего случая: вышли сильные данные по инфляции, но доходности упали. Значит, рынок торгует не инфляцию, а что-то другое — рост риска рецессии, позиционирование или ликвидность.

## Ключевые узлы передачи

| Узел | Что через него передаётся |
|------|---------------------------|
| US 2Y | ожидания по ставке ФРС — вход почти в любую цепочку |
| US 10Y real | ставка дисконтирования для всех рисковых активов |
| Term premium | фискальный риск и спрос на длинный долг |
| DXY | глобальные финансовые условия за пределами США |
| USD/JPY и EUR/JPY | стоимость и объём carry-финансирования |
| Net liquidity | доступность фондирования для плеча |
| Кредитные спреды | момент перехода от «переоценки» к «стрессу» |
