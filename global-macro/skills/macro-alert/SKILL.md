# MACRO ALERT — срочное сообщение

Срочный ALERT формируется **немедленно**, без ожидания регулярной сводки, когда событие получает 🔴 LEVEL 4 или 🚨 LEVEL 5. Для 🟠 LEVEL 3 допустим сокращённый ALERT.

## Когда ALERT обязателен

- сюрприз в данных, существенно отличающийся от консенсуса (особенно NFP, CPI, PCE, ISM);
- неожиданное решение или смена тона центробанка (ФРС, BOJ, ECB, BOE, PBOC);
- провальный аукцион гособлигаций (слабый bid-to-cover, крупный tail, низкий indirect);
- резкий рост длинных доходностей (US 30Y, JGB 30Y, Gilts 30Y) — duration stress;
- быстрое движение USD/JPY или EUR/JPY, особенно укрепление иены;
- расширение OAT/Bund или BTP/Bund спреда с падением банковских акций;
- стресс фондирования: SOFR выше IORB, всплеск использования SRF, падение резервов;
- геополитический или энергетический шок с движением нефти;
- признаки банковского или суверенного стресса.

## Правила заполнения

**РЕАКЦИЯ РЫНКА.** Указывай изменение и базу отсчёта: для доходностей — в базисных пунктах (б.п.) от уровня до релиза, для остального — в процентах и абсолютном уровне. Если данных по активу нет — пиши «нет данных», **не выдумывай числа**. Отдельно отмечай, если реакция **противоречит** содержанию новости — это самостоятельный сигнал (см. change detection в `macro-monitor`).

**ЧТО ЭТО ЗНАЧИТ.** Только механизм, без воды: через какой канал событие доходит до рынков (ставки, ликвидность, премия за срок, кредитный спред, carry).

**МАКРОЭКОНОМИЧЕСКИЙ ВЫВОД.** Одна мысль: подтверждает ли событие текущий режим, ослабляет его или ломает. Если ломает — назови новый режим-кандидат из `regime-scenarios`.

**MARKET IMPACT.** 🟢 позитив / 🟡 нейтрально-неоднозначно / 🔴 негатив — для каждого класса. Для облигаций 🟢 = рост цен (падение доходностей). Для USD 🟢 = укрепление доллара (это не оценка «хорошо/плохо», а направление).

**RISK LEVEL.** Ставится по шкале из `macro-monitor`. Не завышай — инфляция уровней убивает ценность агента.

## Обязательные приписки

- Неподтверждённое событие — префикс **⚠️ НЕПОДТВЕРЖДЕНО** в строке СОБЫТИЕ, с указанием источника и того, чего не хватает для подтверждения (см. `source-verification`).
- Если данные могут быть пересмотрены (NFP, GDP, TSF Китая) — отметь это в выводе.
- Каждый ALERT после отправки записывается в журнал через `signal-memory`; при последующем развитии событий обновляй запись, а не дублируй ALERT.

## Сокращённый формат (LEVEL 3)

```
🟠 MACRO SIGNAL — [показатель/событие]
Факт / прогноз / предыдущее: [ ]
Ключевая реакция: [2-3 самых значимых актива]
Смысл: [1-2 предложения]
Impact: BTC [ ] · Stocks [ ] · Bonds [ ] · Gold [ ] · USD [ ]
```

## Чего не делать

- Не выпускать ALERT на новость, которая не проходит фильтр значимости из `macro-monitor`.
- Не дублировать один и тот же ALERT при повторной публикации той же новости другим изданием.
- Не подменять причинно-следственный анализ пересказом заголовка.
